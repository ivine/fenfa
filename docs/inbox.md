
## 内网后台免登录
后台页面和管理 API 免登录；上传及安装包解析保留 Token 校验；客户端密码设置保持独立。

## 默认进入管理后台
访问 localhost:8000 默认进入管理后台，下载目录保留在 /catalog，下载页返回和客户端验证跳转使用下载目录。

## GitHub 多架构容器发布
通过 GitHub Actions 手动构建 AMD64 和 ARM64 镜像并发布到 GHCR，供 64 位树莓派通过 Docker Compose 拉取。使用工作流自带的 GITHUB_TOKEN。

## 平台命名统一
将中文界面和中文说明中的“变体”统一称为“平台”，同步按钮、提示和筛选文案；保留现有 API 字段和数据结构。

## 按架构独立构建镜像
将 AMD64 和 ARM64 拆为两个手动触发的 GitHub Actions 工作流，使用各自原生 Runner 和独立镜像标签，日常仅构建 ARM64。

## 上传平台参数命名
上传接口改用 platform_id，兼容 variant_id；同步后台上传和命令行脚本。

## 国际化检查
检查中英文翻译键和占位符，统一平台术语，修复硬编码文案与语言切换问题。

## 分架构部署文档同步
同步中英文 README 的镜像地址、架构选择、GitHub 构建和 Compose 更新步骤，说明旧 latest 标签与本地脚本默认值。
